# **LDS02RR-ROS2-driver**

LDS02RR lidar ROS driver.

## Description

Tested with ROS2 and ROS Humble.

## Hardware
Required hardware:
- LDS02RR lidar
- Lidar interface module
- Linux SBC (eq. Raspberry Pi / Banana Pi)

## ROS package & node

**Package**: Lidar_ros2

**Node:** lds_lidar
